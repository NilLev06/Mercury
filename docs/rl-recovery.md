# RL: выход из контакта, версия 5

Запуск прежний: `Digital Fly Car.command` → «Обучить RL — 120 эпизодов».
Сначала 30 задач около переднего/заднего контакта с цилиндром или стеной,
затем по 30 задач прямого поиска, с одним цилиндром и в сложной арене.
После окончания: «RL-муха: коридор».

При первом обучении новой версии старая v4 таблица сохраняется побайтно в
`artifacts/rl/q-policy.json.v4.bak` (при совпадении имени создаётся следующий
номер). Для новых признаков создаётся новая v5 таблица. Последующие запуски
v5 продолжают её обучение. До первого переобучения старая таблица продолжает
работать через адаптер только для исполнения — с новым защитным слоем.

Что поменялось:

- В наблюдении есть передний/задний контакт, предыдущая команда, неудачное
  направление и конкретное заблокированное действие.
- После 0,4 с контакта без движения по энкодеру направление считается
  неудачным. Если поворот сам задевает задней частью цилиндр, пробуется
  другая команда в разрешённом направлении. После нового удара память
  удерживается минимум 0,8 с; затем очищается после 1 см фактического
  перемещения. Краткое исчезновение контакта не отменяет выход.
- Для неизвестных состояний и равных Q используется воспроизводимый
  осторожный выбор; обучающая epsilon-случайность остаётся, но только среди
  допустимых действий.
- Обновление Q учитывает те же запреты, что и выбор команды.
- Контакт относится к реально пересекающему машину препятствию, а не просто
  к ближайшему центру цилиндра. Габариты коллизии не уменьшались.

Это RL с явным защитным/восстановительным слоем, а не полностью выученное
управление. Направленные контакты имитируют бамперы. При переходе на железо
потребуется источник таких сигналов; они не вычисляются из передней камеры.
Награды и критерий достижения цели не изменены. Устойчивая остановка у шара
по-прежнему не обучается.
