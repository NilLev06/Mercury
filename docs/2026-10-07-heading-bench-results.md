# Первый стенд нейронной ориентации

## Что сделано

Отдельный `HeadingRing` хранит три массива активности: компас и две группы
сдвига. Обновляется активность, а не скалярный угол. Фаза считывается только
для измерения. Эффективные знаковые косинусные связи, 16 секторов и постоянные
времени синтетические. Это контрольная модель механизма, НЕ реконструкция
149 нейронов FlyWire и НЕ точное воспроизведение модели из публикации.

Контекст исследования:
https://www.nature.com/articles/s41593-024-01766-5
https://www.nature.com/articles/nature22343

## Проверка

12 начальных фаз, 10 скоростей от −2 до +2 рад/с, 120 двухсекундных поворотов.
Шаг измерения 10 мс, внутренний шаг не больше 2 мс.

- Максимальная ошибка короткого поворота: 2.027°.
- Удержание 10 секунд без входов: пренебрежимо малый численный дрейф.
- Идеальная зрительная подсказка возвращает фазу за 2 секунды в 12 проверках
  после поворота на последней скорости серии (+2 рад/с).
- Без рекуррентного feedback контраст исчезает (~1.3e−15).
- Без входа вращения представление не обновляется: ошибка 57.3° после
  двух секунд при 0.5 рад/с.
- 20 секунд при 2 рад/с: ошибка 9.95°, контраст вырос с 0.4 до 0.513.

Фаза подсказки на этом стенде — искусственный сенсорный вход, не результат
камеры; это НЕ абсолютный угол, скрыто поданный действующей машинке. Модуль
не импортирует симулятор, учителя или checkpoint.

## Ограничение, найденное ревью

Первые гармоники имеют единичное усиление при покое. Поэтому сохранение фазы
является нейтральной памятью, а не доказательством устойчивого биологического
аттрактора. Амплитуда зависит от подсказки и меняется при движении. Нет проверки
биологической точности активности, восстановления bump после возмущений,
самопроизвольного возникновения единственного bump или реалистичного шума.
Нельзя подменять этот результат утверждением «компас мухи воссоздан».

## Анатомическая часть

Версионированная официальная таблица:
https://github.com/flyconnectome/flywire_annotations/tree/v2.1.0

Сопоставлены все 149 выбранных root_id: 74 left, 75 right. Типы hemibrain
совпадают по количествам с исходным извлечением. Предсказанные медиаторы:
109 acetylcholine, 39 glutamate, 1 serotonin. Не назначать всем Delta7
автоматически один знак действия. Поля позиции и soma не являются секторами
терминалей EB/PB. Не сортировать root_id для назначения углов.

Полные метрики, поля таблицы и SHA256:
`artifacts/imitation/reports/heading-circuit-20261007/bench.json`.

Воспроизведение (out должен быть новым файлом):

```sh
python -m fly_brain_rc.neural.heading_bench --out /tmp/heading-bench-new.json
```

Для полного отчёта с аудитом аннотаций:

```sh
python -m fly_brain_rc.neural.heading_bench \
  --out /tmp/heading-bench-full-new.json \
  --anatomy artifacts/imitation/reports/heading-circuit-20261007/anatomy.json \
  --annotations .local/connectome/annotations/flywire-v2.1.0.tsv
```

## Следующий переход

Для анатомической модели получить обоснованное сопоставление секторов по
терминалям/колонкам либо подтвердить его независимыми морфологическими данными.
Затем строить анатомически ограниченную динамику, сравнивать с этим baseline
и проверять восстановление после возмущений/абляции/шум. После этого — камера
и контур поворота; только затем — подключение к машине. Текущий best checkpoint,
запуск из веб-интерфейса и bicycle не изменены.
