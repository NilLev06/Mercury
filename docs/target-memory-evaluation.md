# Проверка памяти цели и обхода — 2026-10-03

Сравнение HEAD dbfd3a9 (v6) и нового контроллера v7. Один и тот же
q-policy.json, seed 0, реальные кадры MuJoCo и детекторы; без обучения.
Лимит 2400 тиков / 48 с, действия удерживаются 0,2 с и прерываются при
смене режима. Арена без препятствий или с цилиндром радиуса 0,28 м
в (1,15; y), цель (2,35; 0). Критерий успеха прежний: расстояние от
задней оси до цели не больше 0,5 м, не устойчивая остановка.

| Карта | Успех v6 → v7 | Минимум до цели, м | Удары v6 → v7 |
| --- | --- | --- | --- |
| Прямая | да → да | 0,497 → 0,497 | 0 → 0 |
| Цилиндр y=0,18 | нет → нет | 1,525 → 0,927 | 1 → 0 |
| Цилиндр y=0,40 | нет → нет | 1,619 → 1,619 | 1 → 1 |
| Цилиндр y=-0,40 | нет → нет | 1,655 → 1,655 | 1 → 2 |

В прямой задаче обе версии достигли цели за 16,78 с. В первой задаче
с цилиндром v7 раньше увидела цель (1,44 с вместо 3,48 с) и подошла ближе,
но затем потеряла её и за лимит не достигла. Во всех задачах с цилиндром
направление сохранялось около 12 с после последнего наблюдения.
В остальных двух задачах улучшения достижения нет; в одной ударов больше.

Это проверка механизма на старой таблице, не доказательство решения
навигации и не статистически значимая оценка обученной v7. Память помогает
сохранить намерение, но не заменяет поиск проходимого маршрута. Не следует
обещать, что очередной цикл обучения сам решит оставшиеся случаи.
